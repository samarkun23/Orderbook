# Orderbook

- This is a simple order book implementation in Rust. It allows you to add buy and sell orders, and it will match them based on price and it's give you the best available price for each order.
- This is optimized for performance . It's uses a BTreeMap to store the orders which allows for efficient insertion and retrieval of orders based on price. The order book is designed to be simple and easy to understand, while still being efficient and performant.
